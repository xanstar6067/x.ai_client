Отказ от ответственности

Это приложение представляет собой клиентский интерфейс для API сторонних разработчиков ИИ.

Пользователи предоставляют и управляют собственными ключами API. Все запросы к API отправляются непосредственно выбранному поставщику с использованием учетных данных пользователя. Любые расходы, связанные с использованием API, несет исключительно пользователь.

Приложение не обрабатывает платежи и не перенаправляет запросы к ИИ через серверы, принадлежащие разработчику.

Некоторые функции, такие как автоматическая генерация заголовков чата, могут выполнять дополнительные запросы к API.

Расчеты токенов и цен являются приблизительными и могут отличаться от фактического выставления счетов поставщику.
