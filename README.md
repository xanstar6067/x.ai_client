# XAI Client for Android

Полноценный Android-клиент для работы с моделями Grok от xAI.

[![Watch the demo](https://img.youtube.com/vi/c_jTSzIJyw0/maxresdefault.jpg)](https://youtube.com/shorts/c_jTSzIJyw0?feature=share)

Приложение ориентировано на удобную работу с ИИ-моделями, поддержку мультимедийных возможностей API xAI и расширенное управление чатами.

## Возможности

### Работа с API xAI

* Поддержка собственного xAI API Key
* Проверка валидности API ключа
* Получение списка доступных моделей
* Возможность выбора нужных моделей из списка

### Чаты

* Текстовые чаты
* Чаты генерации изображений
* Чаты генерации видео
* Поддержка Grok 4.20 Multi-Agent

### Управление сообщениями

* Копирование текста сообщений
* Редактирование сообщений
* Редактирование ответов модели
  (кроме фото и видео чатов)
* Повторная генерация сообщений
* Удаление отдельных сообщений
* Ветвление диалогов внутри одного чата

### Управление чатами

* Копирование чатов
* Удаление чатов

### Резервное копирование

* Создание резервной копии данных приложения на накопитель
* API ключ не включается в резервную копию
* Раздельное резервирование отдельных чатов пока не реализовано

### Интерфейс

* Настраиваемый тактильный отклик
* Раздельная настройка вибрации:

  * для интерфейса
  * для ответов модели

## Важно

Для работы приложения требуется собственный API ключ xAI.

Приложение не предоставляет доступ к сервисам xAI и не включает бесплатный лимит запросов.

Использование API xAI тарифицируется отдельно и может привести к значительным расходам в зависимости от выбранной модели и объёма запросов.

# XAI Client for Android

A full-featured Android client for interacting with Grok AI models by xAI.

The application is focused on convenient AI interaction, multimedia capabilities of the xAI API, and advanced chat management features.

## Features

### xAI API Support

* Custom xAI API Key support
* API key validation
* Fetch available models list
* Select preferred models from the list

### Chats

* Text chats
* Image generation chats
* Video generation chats
* Grok 4.20 Multi-Agent support

### Message Management

* Copy message text
* Edit messages
* Edit model responses
  (except image and video chats)
* Regenerate messages
* Delete individual messages
* Chat branching within a single conversation

### Chat Management

* Copy chats
* Delete chats

### Backup System

* Create full application backups to device storage
* API keys are excluded from backups
* Separate chat backup is not implemented yet

### Interface

* Configurable haptic feedback
* Separate vibration controls:

  * interface interactions
  * model responses

## Important

Your own xAI API key is required to use the application.

This application does not provide access to xAI services and does not include free request quotas.

xAI API usage is billed separately and may result in significant costs depending on the selected model and request volume.
